How X gets in: sift add-x <handle> routes the handle through the bridge in config.toml ([x] bridge_url). Public Nitter instances are unstable — for reliability, self-host Nitter/RSSHub or use an RSS.app feed. The official X API is the heavyweight alternative (pay-per-use reads + auth) and is overkill here.
